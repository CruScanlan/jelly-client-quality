Client Quality

Each rule matches a user, a client app, a device, or any combination of them. Leave a field on "Any" to ignore it. Every enabled rule that matches a playback request applies: transcoding is forced if any of them forces it, and the lowest bitrate cap wins.

Forcing a transcode needs the user's "Allow video playback that requires transcoding" permission. Changes apply to the next playback started; they don't affect streams already playing.
